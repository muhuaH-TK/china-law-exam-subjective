# 中国法律职业资格考试主观题复习

面向中国法律职业资格考试主观题的四阶段复习项目。GitHub仓库：[china-law-exam-subjective](https://github.com/muhuaH-TK/china-law-exam-subjective)。

在WorkBuddy或Codex桌面聊天里完成首次设置、接收资料、完整出题、作答订正、自动保存和考前文档交付，当前版本 **0.3.0**。配套Windows/macOS本地运行核心，无需额外模型API，不附带作者教材、成绩、账号或旧自动任务。

## 开始使用

从[Releases](https://github.com/muhuaH-TK/china-law-exam-subjective/releases)获取安装包：WorkBuddy导入`law-exam-study-0.3.0-skill.zip`；Codex使用`china-law-exam-subjective-0.3.0-codex-plugin.zip`中的本地插件市场。打开你选择的本地复习目录，点击“法考主观题复习”入口或在聊天说“开始复习”。见[安装与开始复习](docs/安装与开始复习.md)。

AI在聊天中引导年度、选做、资料、课程进度和必要授权，并检查Python3.11以上环境。默认09:30自动学习、22:00监测，首次可修改；监测从第二阶段起。后续每日任务自动安排，每次真实交互后保存，无需每天说开始或暂停。WorkBuddy按定时任务的日期运行会话使用，所有聊天共享进度。

资料可直接发在聊天中，也可指定本地文件或资料目录，AI自动整理登记。项目绑定在复习目录的`.law-study/project.json`，学习资料与进度通常位于其`.law-study/data`；可绑定已有实例，源码目录内不保存正式实例。不默认上传云端项目资产库，私人目录不随代码发布。

正常使用无需设置网页、手写JSON或输入命令。技能包含后台助手，MCP为可选连接；原生自动任务必须实际创建并核对回执，生成配置不等于已在桌面运行。

## 四阶段安排

| 阶段 | 时间 | 内容 |
|---|---|---|
| 一 | 至客观题考试结束日 | 网课主线、教材配合；完成单元后教材原题考查，暂不理论背诵 |
| 二 | 客观题结束次日至成绩公布日 | 需要时学冲刺课；理论背诵填空，非理论科目每日三套，另等量历史订正 |
| 三 | 成绩次日至主观题考试前第8日 | 理论背诵默写、每日五套，历史订正由用户主动选择 |
| 四 | 主观题考试前第7日至前1日 | 自主背诵、错漏资料和聚焦阅读，不要求做题 |

日期核验适用年度官方公告，程序联网受限时可由AI真实检索并回填依据，不套往年日期。选行政法排除商法，选商法排除行政法，未明确六科轮换。订正先讲知识点，等待真实重答后按“知识点—案情—错漏—答案”讲评。D2/D4/D7/D14从首次错误日固定起算，错误不回D2，D14后未独立掌握每14天候选。完整规则见[复习规则](docs/复习规则.md)。

## 资料、监测和导出

主动资料与范围内授权检索并存；在线AI处理必要内容须用户允许，不向无关网站外发整库。主动文件不设大小、格式或资料科目限制，由AI自动登记并分块保存原件。暂不能自动解析的格式、较大资料也保留原件，交由所选AI按需处理，不要求先拆分再提供。资料可包含选做已排除的科目，课程、出题和监测仍按生效科目筛选。导入不等于可出题或已经学完。TXT/Markdown/Word可提取文字，PDF提取可安装pypdf，扫描件和图片由AI实际获授权的能力核验。

题源监测**从第二阶段开始**。预置本项目已有的李佳、孟献贵、左宁微博主页，默认关闭，可补充来源；第一阶段可以配置和授权，不抓取、不处理欠项。核验身份并持续授权后支持公开RSS/JSON和AI浏览器采集，新增、补答案、更正共享每日预算，缺页缺答案不发题。提供本机worker、Windows计划任务和macOS启动项模板，以及AI客户端定时提示词。保存配置、生成模板与实际运行分别验收，见[自动化与监测](docs/自动化与监测.md)。

导出中文PDF、可编辑Word、Markdown专题需`python -m pip install -r requirements-export.txt`。PDF页码按最终物理页核验，交付前仍需渲染检查。Word引用明确指同次PDF页码。资料交付不记录学习完成。

## 检查与交付

`python run.py doctor`检查功能与依赖，status查看指定实例。开发检查：`python -m unittest discover -s tests -v`与`node --check static/app.js`；源码打包：`python tools/package_release.py`。Node仅用于开发检查。源码包按白名单逐文件核验，不含实例。

AI操作字段见[AI工作流](docs/AI工作流.md)，实际验收边界见[功能状态](docs/功能状态.md)。单设备维护实例，迁移复制完整目录，停旧机任务并重生成新机连接。Windows/macOS CI已配置，未运行的CI和真实客户端验收不能写通过。
