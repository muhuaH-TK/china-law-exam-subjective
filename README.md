# 法考复习通用项目

由不同AI工具共用资料、进度和错题的法考主观题项目，当前源码版本 **0.2.0**。优先适配WorkBuddy与Codex，提供Windows和macOS入口。你提供自己的资料与实际进度，AI负责阅读、语义讲评和检索，本机程序保存规则、记录、题源版本和任务状态。无需额外模型API，不附带作者教材、成绩、账号或旧自动任务。

## 开始使用

需要Python 3.11以上。Windows双击启动.cmd或在源码目录运行`python run.py`；macOS运行`python3 run.py`，也可为启动.command赋予执行权限后打开。本机页面分步引导年度、备考状态、行政法/商法/未确定、资料授权、课程和监测选择；按Ctrl+C停止。页面只监听127.0.0.1，不作为公网网站部署。

个人实例默认在用户主目录`.law-exam-study/default`；可用--data-dir明确选择源码之外的路径，程序拒绝将正式实例放入源码目录，防止随GitHub发布。

运行`python run.py client-config`（自选实例附上同一--data-dir），在个人实例integration目录生成两款AI的MCP配置、首次使用提示词和定时提示词。按[使用与AI接入](docs/使用与AI接入.md)添加本地连接，再发送“首次使用.txt”。生成文件不修改全局设置，不等于已经连接或创建任务。

## 四阶段安排

| 阶段 | 时间 | 内容 |
|---|---|---|
| 一 | 至客观题考试结束日 | 网课主线、教材配合；完成单元后教材原题考查，暂不理论背诵 |
| 二 | 客观题结束次日至成绩公布日 | 需要时学冲刺课；理论背诵填空，非理论科目每日三套，另等量历史订正 |
| 三 | 成绩次日至主观题考试前第8日 | 理论背诵默写、每日五套，历史订正由用户主动选择 |
| 四 | 主观题考试前第7日至前1日 | 自主背诵、错漏资料和聚焦阅读，不要求做题 |

日期核验适用年度官方公告，程序联网受限时可由AI真实检索并回填依据，不套往年日期。选行政法排除商法，选商法排除行政法，未明确六科轮换。订正先讲知识点，等待真实重答后按“知识点—案情—错漏—答案”讲评。D2/D4/D7/D14从首次错误日固定起算，错误不回D2，D14后未独立掌握每14天候选。完整规则见[复习规则](docs/复习规则.md)。

## 资料、监测和导出

主动资料与范围内授权检索并存；在线AI处理必要内容须用户允许，不向无关网站外发整库。导入不等于可出题或已经学完。TXT/Markdown/Word可提取文字，PDF提取可安装pypdf，扫描件和图片由AI现有的获授权能力核验。

李佳与左宁主页作为默认关闭的候选，可补充来源。核验身份并持续授权后支持公开RSS/JSON和AI浏览器采集，新增、补答案、更正共享每日预算，缺页缺答案不发题。提供本机worker、Windows计划任务和macOS启动项模板，以及AI客户端定时提示词。保存配置、生成模板与实际运行分别验收，见[自动化与监测](docs/自动化与监测.md)。

导出中文PDF、可编辑Word、Markdown专题需`python -m pip install -r requirements-export.txt`。PDF页码按最终物理页核验，交付前仍需渲染检查。Word引用明确指同次PDF页码。资料交付不记录学习完成。

## 检查与交付

`python run.py doctor`检查功能与依赖，status查看指定实例。开发检查：`python -m unittest discover -s tests -v`与`node --check static/app.js`；源码打包：`python tools/package_release.py`。Node仅用于开发检查。源码包按白名单逐文件核验，不含实例。

AI操作字段见[AI工作流](docs/AI工作流.md)，实际验收边界见[功能状态](docs/功能状态.md)。单设备维护实例，迁移复制完整目录，停旧机任务并重生成新机连接。Windows/macOS CI已配置，未运行的CI和真实客户端验收不能写通过。
