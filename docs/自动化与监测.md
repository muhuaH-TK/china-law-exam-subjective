# 自动化与题源监测

自动学习以所选AI客户端的原生定时任务为主要入口。首次在聊天确认时间和唯一运行设备后，AI读取automation_plan、认领设备，再调用宿主真实定时工具创建任务并登记实际ID/回执。默认09:30直接安排当天学习，22:00在第二阶段起执行固定监测；不要求每天说开始，每次有意义交互后自动保存。WorkBuddy使用固定任务入口中的日期运行会话，其他客户端按各自原生方式组织。

本机执行器仅用于可直接执行的后台采集和收件箱辅助，不会主动唤醒AI或新建学习聊天。两者实际状态分别记录，不能把模板、勾选设置或本机tick说成桌面任务已运行。详细原生接入和离线续接见[桌面聊天工作流](桌面聊天工作流.md)。下文本机执行器部分是AI/开发者可选操作，不是普通使用者首次设置的必做步骤。

## 来源与授权

题源监测从第二阶段开始。第一阶段允许预先登记来源、核验身份和保存授权，手动检查、定时任务、浏览器采集回填及欠项补处理均不执行；阶段未确认时同样等待。进入第二阶段后仍须已启用且授权有效，不因阶段切换自动授权。通常以当年已核验的客观题考试结束次日为起点；用户明确选择当前适用阶段时按该选择执行。

提供本项目已有的三位老师网页作为公开主页候选，默认关闭，首次启用前实际核对账号名称、UID、科目与访问情况：

| 来源 | 网页 | 学科范围 |
|---|---|---|
| 李佳 | https://weibo.com/u/1552849431 | 行政法 |
| 孟献贵 | https://weibo.com/2342740757?refer_flag=1001030103_ | 民商法，来源归入民事综合；每题另核验科目 |
| 左宁 | https://weibo.com/u/3153511812 | 刑事诉讼法 |

使用者可补充、关闭来源。三来源是本次明确选定的通用候选，不复制旧个人实例的监测授权、账号、历史游标或欠题。旧实例调用source_action(action=presets)可增量添加缺少的候选，不重复添加、不覆盖自定义来源或启用状态。孟献贵主页的商法内容仍受选做范围限制；选行政法时不得把商法主导案例当作民事综合出题。

本地页面可登记来源、选择browser/rss/json，填当前身份核验和持续监测范围，再明确启用。也可使用source_action(action=presets)添加关闭状态候选，然后configure。资料授权与监测授权分别存在；只允许用户提供资料时不会开始联网采集。选做明确后例行运行排除另一科来源。monitor_state.gate返回当日阶段是否允许监测；第一阶段运行run_monitor会返回waiting_stage2，不能把它说成已检查或没有更新。第三、四阶段继续依原授权监测；考试日后的监测是否继续仍由独立授权决定。

browser由WorkBuddy/Codex已有且获授权的浏览器读取，程序不抽取Cookie、保存密码或自行登录。公开RSS/Atom和JSON Feed由run_monitor直接有界读取；仅HTTPS公开地址，同网站重定向和每跳公开地址校验，内网/本机地址拒绝。不是把任意网页当作RSS。

## 采集与核验

所有来源每日共享默认10题预算，可配置1至100。新增、答案补充、同帖更正都计入；相同ID且正文/图片哈希相同不重复消费。保留原帖URL、稳定ID、发布时间、实际工具引用、捕获时间和每版哈希。每个来源先获得新增检查机会，再处理欠项；未处理条目保留monitor_backlog，不能因前移游标丢失。预算按配置时区的日期计算。

浏览器实际读取后调用ingest_source_capture：

```json
{"version":"最近版本","payload":{"source_id":"已授权来源ID","on":"实际当地日期","method":"client_browser","evidence":"实际浏览工具引用及账号核验","entries":[{"external_id":"原帖稳定ID","url":"原帖完整网址","title":"真实标题","text":"实际读取完整正文","published_at":"实际发布时间","images":["原帖所有相关图片网址"]}]}}
```

没有读取到内容、访问被拒或缺图片时如实标记，不能用“没有更新”掩盖失败。预算满后停止内容处理，保留待办；缺页/续图/答案的条目仍为待核验，不能出题。首次关闭来源后不补它的历史欠项。

search_only结果为candidate，用户选定后source_action(action=approve_import,payload={source_id,item_id,authorization})；search_and_import在既有授权范围内自动imported。导入仍不等于完整题源或已学习。read_source_capture逐条读取后，核对全部原题、题号、案情和答案；用learning_action登记完整题源及答案版本。题目和答案分帖时匹配原题号、事实与版本，不能仅凭相邻发布日期配对。帖子更正不覆盖已使用原题和旧答案，追加新版本和更正说明。

## 本机执行器

先在页面保存时区、提醒/监测选择、时间和每日预算。学习时间在这里指后台触发时刻，不是每天学习时长。

指定唯一运行设备后可以前台运行，无需创建系统任务：

```text
python run.py status --data-dir "个人实例目录"
python run.py schedule-enable --data-dir "个人实例目录" --version "刚才返回的version" --instruction "用户明确指定本机运行自动化"
python run.py worker --data-dir "个人实例目录"
```

worker每30秒检查，在约定时刻后生成一次当日学习入口并执行已授权公开订阅；需要浏览器的来源进入待办。也可用tick仅执行一次。无变化无待办时不输出周期通知。关闭窗口会停止前台运行，不伪称已常驻。提醒在个人实例inbox中，也可由AI工具get_inbox读取；程序本身不发邮件或社交通知。

希望关闭窗口后仍运行，可使用schedule-enable生成的integration/windows-task.xml或macos.plist。**生成不等于安装**。

- Windows：使用命令返回的精确schtasks创建命令（不含覆盖/F）。在“任务计划程序”检查本实例名称`lawstudy.实例ID`、最近运行结果，避免重复安装。使用当前用户身份，隐藏窗口，不提升为管理员、不改作者旧任务。
- macOS：将生成的macos.plist复制到自己的`~/Library/LaunchAgents/lawstudy.实例ID.plist`，然后以当前用户通过`launchctl bootstrap gui/用户ID 该完整路径`载入。不要作为系统root任务安装。

每5分钟启动一次tick，进程锁防止重叠；实例文件仍有独立写锁和内容版本检查。首次以当前用户实际运行tick，核对runtime.last_tick_at和last_status；模板能生成不代表系统已接受。迁移到另一台设备后必须重新指定，原机卸载本实例系统任务，禁止双机并行写入。

当天电脑晚开时只准备当天入口，不补漏做题量。未结束的真实作答先续接。暂停、非本年度参加状态或考试日后不再生成学习题；监测是否继续由独立授权决定。任务故障不改学习完成状态。

## AI客户端的定时任务

运行client-config，生成本实例“学习定时提示词.txt”和“监测定时提示词.txt”。在选定AI客户端支持的定时任务入口创建任务，使用生成的文字、同一实例路径、约定时区和触发时间；不复制作者聊天ID或旧任务。客户端须保持可运行，浏览器须实际可用并登录必要账号。具体可用入口取决于客户端版本，不编造不存在的CLI唤醒指令。

客户端任务通过MCP读取状态，继续浏览器采集、题源核验或交互学习；收到用户答复前停止，不替用户作答。没有浏览器能力时，保留待办并请用户提供原题或换到具备能力的AI。无需新增模型API密钥，也不把本机MCP暴露到公网。

本机采集器和AI任务共用游标、版本、预算和锁；两边都开也不能绕过全局预算。监测任务保持安静，只在实质更新、失败或需要用户行动时通知。关闭任务应分别在系统计划和客户端中停止，配置勾选变更本身不证明外部任务已经移除。
