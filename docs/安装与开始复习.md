# 安装与开始复习

本技能适用于中国法律职业资格考试主观题复习，可结合备考阶段、课程进度和已有资料安排每日学习，开展题目练习、订正讲评与理论背诵，并持续保存学习进度。错题会保留原始作答、错漏及订正记录，按D2／D4／D7／D14等间隔安排回顾，并在考前按知识点整理，帮助巩固记忆、减少重复遗漏。也可在调整考试阶段、科目、题型及复习规则后，复用于其他考试备考或其他内容的学习。

本项目在你使用的WorkBuddy或Codex桌面聊天中运行，无额外模型API。安装准备、功能测试和正式学习是三个明确状态，测试不会自动成为正式复习。

## 下载和客户端加载

从[Releases](https://github.com/muhuaH-TK/china-law-exam-subjective/releases)获取公开的0.4.3包，无需加入作者的私有仓库：

- WorkBuddy：law-exam-study-0.4.3-skill.zip，自包含运行核心。由AI根据当前客户端实际“上传技能”入口引导，不能把下载完成当加载成功。
- Codex：china-law-exam-subjective-0.4.3-codex-plugin.zip，解压后包含本地市场和插件。AI先查当前官方方式、实际工具及界面；可用时后台添加本地市场，再通过实际客户端核验安装/启用。不能凭写入配置、源码存在或未核实的菜单位置宣称安装完成。
- 也可让有本地文件/执行能力的AI打开源码、读取AGENTS.md使用；MCP是可选连接，用户无需手写配置。

一次必要的Python3.11以上准备、客户端安装选择、权限确认或重启由AI按实际缺项引导；其他步骤尽量后台完成。客户端加载需在新聊天实际识别技能并调用后台验证，代码测试不代替这个步骤。尚未安装技能时可将本说明交给宿主AI，选择安装或源码方式。

## 第一次使用的顺序

1. 优先创建专用桌面项目。你不想创建或当前无法创建时可跳过，继续聊天使用；AI分别记录已创建、用户跳过或创建受阻。
2. 选择本地复习目录，或告诉AI位置让它后台新建，绑定资料和进度。文件夹不同于桌面项目；已有实例直接续用，不新建空记录。
3. 选择先测试还是正式准备。测试使用独立实例，同样严格逐项引导；你明确允许后可使用合成资料或暂不提供教材；原正式记录不受影响，测试任务完成后停用。正式学习需你明确确认一次，随后每天自动安排。
4. 在聊天完善年度、选做、资料课程、必要授权、时区与时间。默认09:30学习、第二阶段起22:00监测，可调整。首次直接展示下方PDF、Word及中国法律辅助技能的链接和用途，记录你的选择，不默认安装。
5. AI查询已有真实任务、恢复登记或创建并回读。固定任务名不变，每天新建名称为当地日期YYYY-MM-DD的学习聊天；监测使用固定维护入口。WorkBuddy日期运行会话的名称/归属也需实测，无法实现处明确告知。

之后直接在聊天看完整题目、作答、学习及重答或反馈课程进度。每次真实交互保存，无需每天说开始或暂停；未回复保留待答，离线后按当天续接，不累计旧题债。可以以后补建项目，关联原有实例和任务。

选择后，AI先核对已安装情况、上游许可、依赖和当前客户端支持方式，再引导安装并实际调用验证；分别记录已验证、待验证、失败或暂不安装。仅下载或推荐不算安装完成。缺少辅助技能时继续现有能力支持的复习，具体缺项如实说明。外部技能不随本项目打包，也不继承本项目MIT许可；think-like-me不在推荐范围。

## 资料与旧版本

直接发送附件，或指定本地文件/资料目录，AI自动登记，不默认上传云端项目资产库。项目自身不限制大小、格式或科目，暂不能解析仍保留原件。正式第一阶段依课程与教材原题，没有适配原题可核验后跳过；测试免教材不改变正式规则。

0.2.x/0.3.x实例保留教材、原答、成绩、错题和授权，告诉AI原目录即可续用。旧版补齐一次项目选择和正式模式确认；已有任务先查询恢复登记，不重复创建。旧安装包缓存不自动变成0.4.3，更新后必须再次核验客户端加载版本。

首次导出AI检查reportlab与pypdf，按运行核心requirements-export.txt后台准备并遵循宿主审批，不要求你输入命令；失败不影响日常聊天。PDF页码、中文表格和视觉检查分别验收。

## 迁移和验收

换目录用聊天中的受控迁移，AI先停旧任务、完整备份核验，再复制绑定、同步任务，保留原目录及恢复依据；不要求你手改JSON。跨设备传输仍需用户允许的实际传输方式及新端核验。

文件下载、环境、配置、客户端加载、后台调用、项目绑定、任务创建、立即运行、正常到点、完整学习和监测/导出分开验收。正常到点至少一次真实成功才标通过，立即运行不能替代。客户端与操作系统分别记录，尚未完成的保持待验收；doctor不代表全部就绪。
