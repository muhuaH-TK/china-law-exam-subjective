# 安装与开始复习

本项目在你已经使用的WorkBuddy或Codex桌面聊天中运行。安装后有“法考主观题复习”技能入口，首次说“开始复习”，AI引导你选本地复习目录和完成准备；之后每天由已确认的任务自动安排。无需日常打开设置网页、输入命令或填写配置。

## WorkBuddy

1. 从本仓库[Releases](https://github.com/muhuaH-TK/china-law-exam-subjective/releases)下载`law-exam-study-0.3.0-skill.zip`。私有仓库需要访问权限。
2. 在WorkBuddy技能入口使用“上传技能”导入这个包。入口名称以实际客户端为准；技能包已包含运行核心，不必另复制源码。首次需要Python3.11以上时，让AI检查并引导准备一次。
3. 打开或选择一个本地复习工作空间，可以在同一项目下组织聊天。点击技能或发送“使用法考主观题复习技能，开始复习”。告诉AI资料文件或目录的位置，也可直接发送附件。
4. 按聊天确认年度、选做、资料及必要授权、时区和自动任务时间。AI在客户端真正创建任务并核对回执。默认09:30学习；监测从第二阶段起，默认22:00。需要你亲自确认的客户端权限只在实际需要时引导。

WorkBuddy定时任务使用固定入口，按日期查看每次运行并继续对话。每日学习和监测维护分开，共享同一进度。项目资产库与本地工作空间不同，不要求把教材整库上传腾讯网盘。

## Codex

1. 下载并解压`china-law-exam-subjective-0.3.0-codex-plugin.zip`，其中包含本地插件市场目录、插件及完整核心。
2. 在Codex桌面插件入口添加该本地市场根目录并安装“中国法律职业资格考试主观题复习”。包中的`.agents/plugins/marketplace.json`已指向`plugins/china-law-exam-subjective`。若当前版本需要由AI添加市场，让AI依据实际插件工具操作；不要覆盖用户原有市场或全局配置。
3. 运行插件首次设置入口，或在选定的本地项目聊天发送“开始复习”。AI通过技能引导准备、绑定资料和创建原生每日任务。

也可以让具备本地文件与执行能力的AI打开完整源码包，读取AGENTS.md并使用内含技能；仍全程在聊天操作。MCP是可选接入，不是要求普通用户手写的安装步骤。

## 已有0.2.x数据

告诉AI原学习实例目录，在首次设置时绑定它。无需重置日期、课程、原答、成绩、错题或授权。不同聊天和AI读取同一绑定，不另建空实例。只有一台设备、一个客户端负责自动化；切换聊天不等于迁移任务，迁移前停止旧机原生任务。

## 你实际需要做什么

首次完成必要安装、目录选择和权限确认。之后在聊天看完整题目、作答、学习知识点、重答或反馈课程进度即可。AI每次保存，无需每天说开始或暂停。没有回复的题保持待答；电脑离线后，下次实际运行按当天安排续接，不累计漏做题债。

主动资料不限制项目自身的大小、格式或科目；客户端附件有自身限制时，直接指定本地文件/目录即可。原件不能解析仍保留，AI如实说明缺少的能力，不假装已读到完整图片或题面。

## 验收状态

安装包完整性、聊天后台、共享状态、原生任务计划与回执、MCP规则/图像交付可自动验证。客户端能安装并显示技能、原生任务实际触发、图片在聊天完整呈现、微博登录浏览器采集和操作系统实机必须分别验收。尚未确认的明确标为待验收，源码测试通过不等于已在你的桌面创建了任务。

客户端没有技能/本地插件入口时，先让AI核对实际版本和官方说明，不跳到网页设置冒充桌面适配完成。
