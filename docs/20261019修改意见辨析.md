# 2026-10-19修改意见辨析

对照用户提供的《法考复习技能-可通过代码解决问题清单-20261019.md》与0.3.0源码审查。报告是问题线索，修改以已确认产品规则及可复现行为为准；不操作测试者的真实实例。

| 项目 | 辨析 | 本次处理 |
|---|---|---|
| P1—P4 浏览器、网络、微博、镜像拦截 | 外部能力或环境问题；仅凭无输出不能断言根因。安装浏览器库也不能保证解除网站拦截。 | 保留实际连接验证与失败待恢复，不绕过网站限制、不冒称已验收。 |
| P5/P6 PDF依赖 | 可选导出依赖有意独立，日常复习不应强制安装。 | 导出前一次检查两项依赖，错误给出后台安装位置；由AI处理，不让普通用户输入命令。 |
| P7 第一阶段仅教材原题 | 刻意设计，来自已确认规则。并非import_stream限制真题；实际筛选在issue。 | 不放宽题源；缺题时明确可以跳过单元、补教材，或用户明确要求自拟，真题保留后续使用。 |
| P8 navigation | 0.3.0的AI工作流已有字段，故“完全未写明”不成立；必填、类型与长度不够显眼。 | 补字段表和最小请求；报错直接标字段路径。 |
| P9 旧版本冲突 | 刻意的并发保护，重复沿用版本较容易触发。 | 保留CAS，重读并合并后再保存，不盲目重试。 |
| P10 占位答复建卡 | 可复现：文本非空即能提交，再由grade建卡。正常遵守“真实答复”时不应触发，测试或AI误填仍会污染进度。 | 拦截确定的占位文本；“不会”等真实答复不因短而拒收。新增留痕作废，退出排程，不物理删除原答、分数或历史。 |
| P11 阶段推进和回退 | 无顺序推进器；stage_override已能1—4任意切换及清空。“不能回退”不成立。手动选择有意优先于日历，但缺醒目错位说明。第四阶段是考前一周，并非一个月。 | 展示日历推荐/手动选择差异；有核验依据的错位选择须明确确认，未知日期不捏造考期。首次设置未知年度后可提醒未来年度选了后期阶段。 |
| P11 年份冲突整单回滚 | 原子回滚是保护，不改为悄悄部分成功；有学习记录禁止改年度也是保护。尚无记录但已有旧日期时，换年确会因旧日期卡住。 | 仅尚无学习记录的换年清理当前旧日期、未重选的旧阶段，保留日历证据历史；其他字段仍整笔校验，失败无部分写入。 |
| P12 内容不足 | 不附教材、作者隐私资料和题库是发行边界，不能靠代码补造内容。“真题少于3”也不是所有阶段统一门槛。 | 按当前阶段剩余案例量、已核验未用原题和完整理论主题提示缺口，原件待解析与真正无资料分开；缺理论不阻断案例。 |
| 新1 推荐skill | 辅助技能推荐确实缺失；清单混淆了推荐辅助技能和安装本技能。未安装本技能不可能自行触发其正文。 | 首次主动询问是否了解/安装辅助技能，安装前检查真实来源与兼容性、等用户选择。think-like-me不发行。文档说明本技能未安装时的可选入口，不虚构插件能力。 |
| 新2 自动建项目 | 安装不擅自选择目录是刻意设计；bootstrap本就能创建用户已同意的新目录。 | 主动给出选择已有或由AI新建的简短引导；确认后后台建目录、绑定，不要求用户手动先建。 |

低概率不等于可以忽略：涉及记录污染和学习安排的问题加保护；外部平台能力不以改代码宣称解决。源码变更不自动修正他人的旧占位记录，作废须依据真实误登记说明。
