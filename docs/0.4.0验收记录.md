# 0.4.0 安装与桌面流程改造验收

日期：2026-10-20。基线：0.3.1，提交7d4c578。依据为用户提供的Codex问题归纳、WorkBuddy《AI可解决的问题清单.md》及grilling逐项确认：先建议建桌面项目，用户不建或创建受阻可跳过；固定任务名，每天新建日期聊天；测试独立、任务对账、迁移与验收分项管理。

## 已实现与保护

| 问题 | 最终处理 |
|---|---|
| 安装/测试误作正式复习 | setup不教学；年度或active不等于正式确认；正式仅一次确认，旧记录保留 |
| 桌面项目与目录混淆 | created/skipped/blocked分开；已有实例续用，跳过不阻断，允许后续关联 |
| 测试及免教材依赖聊天说明 | 独立测试实例/工作空间；正式文件、绑定、作答、授权及任务不变；测试不转正式 |
| 宿主有任务、后台没登记 | 完整查询reconcile；唯一匹配恢复；多候选/身份不明/失败阻止创建 |
| 创建重试重复 | CAS创建意图；未知结果先查询找回；明确未创建且用户允许才撤意图重试 |
| 改配置仅重新登记 | verified须实际规格回读，旧规格不能刷新绿色；外部漂移使旧回执失效 |
| 固定任务与日期聊天混淆 | task/run/chat分别保存；日期标题、真实ID、项目归属核验，跨日不能只改名 |
| 界面状态不明 | 能力分层核查、界面操作前后引用，失败状态单列，不以缺工具推断整体不可用 |
| 手动与到点混用 | 真实原生调度事件和聊天结果才确认scheduled_trigger，manual独立 |
| 目录迁移手改几处文件 | 停任务、冻结、完整备份逐文件摘要、复制绑定和集成重生成；源保留，cancel/finalize恢复 |
| doctor/单测当全就绪 | 仅代码依赖说明；验收按客户端/设备/模式/工作空间/版本分别保存 |

不采纳清空PYTHONPATH停用宿主安全垫片的测试“修复”；网络重跑通过不直接认定环境噪声。香港与上海时区当前同为UTC+8，按用户确认保留。第一阶段monitor等待是设计，不能强建；学习已核验时不因监测等待误报未安装。

## 验证范围

完整本地回归124项（原97项在合成夹具中明确模拟正式确认，新增27项安装/任务/运行/迁移回归）。覆盖旧实例未确认不教学、测试字节隔离、回执丢失恢复、并发创建、过期/失败/冲突查询、配置与宿主漂移、跳过项目、真实聊天关联、手动/到点区分、临时任务清理、版本及客户端验收隔离、迁移复制失败/绑定后中断恢复/外部文件变动保护。

Windows/macOS × Python3.11/3.14远程CI以本次提交结果为准；技能官方格式验证、包内逐文件SHA256/CRC与全新解压助手实际执行分别核验。合成宿主回执用于测试保护逻辑，绝不作为真实客户端验收。

## 仍需实机与边界

Codex/WorkBuddy的项目创建、菜单/安装入口、客户端实际加载0.4.0、正常到点原生触发、日期聊天实际创建和命名/归属、图片完整显示、微博登录态与采集、真实材料导出视觉效果仍需对应设备实证。实现的是可查询、可阻止误记的状态与接口，不能据此宣称客户端已具备缺失工具或已触发任务。

本轮未修改作者正式实例、原答、成绩、旧任务、网站权限或全局插件配置，也未升级已安装的0.3.1插件缓存。安装新包后应在新会话确认loaded_version；已有旧任务先对账找回，不重复建。

迁移复制到本机可访问的新目标已隔离验证；跨设备传输及目标端实际核验尚不计为通过。源和核验备份保留，无自动删除；失败目标尚未绑定可恢复源，已绑定须先核验完成，避免两个可写实例。
