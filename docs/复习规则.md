# 通用复习规则 v0.1

本项目固定面向法考主观题。共同科目：理论法、刑法、刑事诉讼法、民事综合（民法＋民诉）；选行政法排除商法，选商法排除行政法，未明确时保留六科。

| 阶段 | 日期边界 | 日常内容 |
|---|---|---|
| 一 | 至客观题考试结束日，含当天 | 网络课程主线、教材配合；每个反馈已完成的单元默认1套适配教材原题；暂不理论背诵 |
| 二 | 客观题结束次日至成绩公布日，均含 | 刚开始课程时采用冲刺课；完整主题背诵与填空；非理论法科目全范围每日3套 |
| 三 | 成绩公布次日至主观题考试前第8日 | 完整主题背诵、语义全文默写；每日5套，选做明确时五科各1套，未明确时六科均衡轮换 |
| 四 | 主观题考试前第7日至前1日 | 自主背诵、历史错漏资料整合、考前聚焦阅读，不要求答题 |

日期从适用年度官方公告核验，保留网址及依据；未公布、失败和冲突如实标注，不套往年日期。日历只推荐阶段，结合使用者真实备考状态确认；晚加入不补做此前全部任务，不参加本年度主观题则暂停升级。用户可明确选择适用阶段，不推定其报考资格。

第一、二阶段当天实际做N套，另选N套历史错题订正，不占新题名额，理论活动不放大案例对应量。历史题不足如实留缺，不重复凑数，不自动拉未来到期题；第三阶段历史订正须明确选择，第四阶段不安排必答历史题。课程、理论和案例分别记录，理论未完成不阻断案例。

先提供完整题面及原设问，不先给答案或知识点提示；用户首答后保存首答评价，讲相关知识点，等其针对错漏重新作答，再按“知识点—案情—错漏—标准答案”充分讲评。知识点列明条件、否定分支、例外、依据和后果，不用提示词或口诀代替实质解释。首答正确部分不造错；重答后一次讲清，不反复强制订正。

有真实错漏才建卡。教学订正后仍留在同一轮候池，首次错误日加2／4／7／14自然日进入D2／D4／D7／D14候选。一次回顾只处理一个节点，不因错误重置D2；延期不等于完成，不在同日重出同题多个节点。教学处理和独立掌握分开。D14后未掌握，从最近一次实际回顾完成日加14日候选；D14及后续有真实独立通过证据才退出，保留历史原答与错漏。候选受阶段、名额及暂停约束，不自动开新任务。

背诵每日默认一个完整主题组，约1000字仅作参考。长主题不可拆、不可删，短主题可以组合。填空与全文默写对应真实材料版本和实际主题范围。全文默写按意思及要点核对，不要求逐字一致。讲解和标准答案篇幅不受1000字限制。

用户主动提供资料优先。搜索、导入和持续监测分别按明确范围授权。第一、二阶段无原题时，只有用户明确要求才自拟具体案例；第三阶段坚持完整原题。缺少可靠答案先补找或换题，确需无标准答案练习由用户选择，AI讲解不虚构正式分数。

自拟题答案和AI参考讲解醒目标“自拟／AI参考，非已公布标准答案”。复测前同步核验是否已有同题可靠答案，找到后改用并保留旧版和更正说明；相似题不能冒充本题标准答案，题源作者答案也不能冒称官方答案。

跨日先续接，完成后计入完成当日题量，首答日期和完成日期分别保存；漏做不累计题债，历史订正不递归增加任务。用户暂停即时保存，完成当日活动后可询问是否继续，等待答复再追加。

第四阶段按知识点串联真实历史错漏，包括后来已订正者并说明改善；题源题号、必要案情、真实原答／错漏、充分答案分开。统计不推算小问失分、不重复分摊。最终PDF／Word有流程图、分类表和经分页核验的导航，不把交付资料视为已学习。

首版单设备内切换AI工具，完整实例手动迁移，只指定一台设备运行自动任务；暂不实时同步。监测恢复在当日预算内按游标补查。在线AI可处理必要资料，不随意发给其他服务；个人资料、成绩和账号不随公开代码发布。

题源监测从第二阶段开始；第一阶段只可预先配置，不实际抓取或补处理欠项。通用候选包括本项目已有的李佳、孟献贵、左宁网页，仍按当前用户授权、科目和预算执行。用户主动上传资料不设大小、格式或资料科目限制；导入已排除科目并不恢复该科课程、出题或监测。

当前哪些规则已由程序支持，哪些需要后续执行器，见功能状态.md。规则文件不等于所有功能已经实现。

缺题预检按当日阶段剩余案例名额计算：第一阶段核对已完成单元的适配教材原题；第二阶段最多3套非理论原题；第三阶段最多5套完整原题，并计入已有待答。不规定所有用户至少有3道真题。第四阶段不设做题库存门槛。理论从第二阶段起需使用者选定材料并核验完整主题；只有原件尚无主题时先整理，缺理论不阻断案例。第一阶段只有真题时保留后续使用；无教材原题可跳过，不擅自自拟。

占位和未答不计真实练习。误登记卡可按用户明确要求留痕作废，退出轮候但不删原答、原分数、回顾记录，不回D2。stage_override支持直接回退和恢复日历；新选择与核验日历冲突时须说明并取得真实确认，未核验的官方日期不猜。
