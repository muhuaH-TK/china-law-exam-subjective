# 桌面聊天执行工作流 · 0.4.0

日常全程在WorkBuddy/Codex聊天操作，AI后台调用随技能助手或可选MCP，不要求用户打开设置网页、输入命令或JSON。先读本页和[安装运行与恢复](安装运行与恢复.md)，复习内容另见[AI工作流](AI工作流.md)和[复习规则](复习规则.md)。

## 第一步：项目选择

首次优先新建专用桌面项目，之后所有设置、每日学习、测试和维护聊天归入该项目。用户不创建或实际创建受阻时允许跳过，状态分别为created/skipped/blocked。目录不是桌面项目；仅选择本地文件夹不记作项目已创建。之后可补建关联原实例和任务。

选择或经同意后台新建专用本地复习目录，bootstrap建立.law-study/project.json与真实数据绑定。已有实例先续用，不重置。源码目录与个人实例分开。跨聊天/AI读取同一JSON，不能只靠模型记忆。

## 使用模式

setup仅安装准备，不出正式题；配置年度不会自动开始教学。测试请求通过create_test创建独立test_workspace，后续请求必须切换；默认合成资料，可暂免教材，无长期任务，测试不能转正式或写回正式记录。正式实例由用户明确确认一次start_formal，之后每日自动开始，不再每天说开始或暂停。旧版数据先补一次模式和项目选择确认，历史全部保留。

首次真实设置包括年度、参与、选做、资料课程、必要在线AI授权、检索范围、时区与自动任务；默认09:30学习、22:00监测。已确认信息不重复询问，不问学习时长。辅助文档技能可选，不默认安装，不发行think-like-me。阶段/日期缺依据不猜，检索失败不当未公布。

## 后台请求

scripts/assistant.py使用实际Python3.11以上解释器，--workspace为用户确认目录，--request读取请求文件或stdin，默认只读context。AI用文件工具组织请求，不把原答拼进shell。写入带最新version，冲突重读，不删锁。完整字段与宿主证据格式见installation指南。

| action | 字段/用途 |
|---|---|
| guide | name=desktop/installation/workflow/rules/monitor |
| bootstrap | client、instruction、data_dir可选，初始化或绑定，不开始正式教学 |
| context | on可选，模式、项目选择、缺项、真实停靠点、计划及分项验收 |
| onboarding | operation=project/start_formal/test_options/capability、payload、version |
| create_test | instruction，返回独立test_workspace；正式文件不变 |
| configure | payload设置、version，不自行授予授权 |
| import / read_material | 自动登记用户附件/指定目录；或按授权分段读单份材料 |
| learning / record | 完整题源和真实交互；学习状态机或课程/启停记录 |
| dates / source / capture / monitor / read_capture | 官方证据、来源授权、真实采集与读取；正式第二阶段起监测 |

## 自动化与聊天

先查询宿主真实任务并reconcile；查询失败/多候选/身份不明不创建。唯一匹配找回登记，未找到则原子reserve_create后真正创建；回执保存失败先查找，不重复创建。verified必须实际回读规格，配置变化先更新宿主同ID、回读再登记，不能只让指纹变绿。模板、收件箱、本机tick不代表客户端已启动。

正式每日任务固定名“法考每日学习”，每天新建当地日期YYYY-MM-DD聊天。run记录固定任务与当天聊天的对应关系；同日重试续接当日主聊天，跨日不能只重命名昨日聊天。监测任务与维护入口固定名“法考题源监测与维护”。项目已创建时核验聊天实际归属；跳过/受阻可继续本地聊天。客户端做不到的环节单列缺项，不编造入口。

测试原生任务默认不开，仅明确测试自动触发时建立独立一次任务，运行后真正停用并回读，失败保持待清理。正常到点触发和立即运行分别验收，不能相互代替。单客户端/设备自动运行；第一阶段监测wait正常，学习已核验时不因此误报未安装。

## 学习与文件

每次检查mode、当地日期、阶段和停靠点；明确暂停/结束或准备模式不教学。跨日先续接，不累计旧题债。未回复保持待答，真实作答/订正/反馈立即保存，不等暂停；不补造答复、分数、用时或完成。理论不阻断案例。

用户附件、本地路径/目录自动登记，资料不限大小、格式或科目，原件不能解析仍保留。不扫描未指定目录，不默认上传云资产库或第三方。首轮及复测完整题面/原设问/必要图片，不提前揭答案；图片无法展示不能省略事实。四阶段及固定轮候见rules，理论版本和讲评见workflow。

迁移必须先实际停任务，使用受控接口核验完整备份，源目录保留；失败按状态cancel或finalize，不手改几处JSON冒充成功。PDF最终实际页码和视觉验收分开；资料交付不记已学完。

## 验收

下载/环境/配置/客户端实际加载/后台调用/绑定/任务创建/手动触发/正常到点/导入/完整题面/订正/跨日/监测/导出分别记录。Codex与WorkBuddy、测试与正式、不同设备不共用通过结论。doctor只查代码和依赖，不能当完整验收。实机未完成项保持pending。
