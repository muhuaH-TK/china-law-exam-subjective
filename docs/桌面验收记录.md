# 桌面聊天改造验收 · 0.3.0

2026-10-19，按用户逐项确认的桌面聊天方案改造。当前交付包含自包含技能包、Codex本地插件市场包及完整源码包。用户正常流程不再以设置网页或手写命令为入口，旧学习实例可以绑定续用。

## 已核验的后台行为

82项隔离测试通过，包含此前65项及17项桌面回归；技能通过官方quick_validate校验。安装包逐文件SHA256及CRC核验，并在全新解压目录实际执行技能助手读取规则，无需作者目录或原有MCP连接。

| 项目 | 核验结果 |
|---|---|
| 默认入口 | 不打开浏览器，不擅自建立用户实例 |
| 项目绑定与换聊天 | 保持同一实例、原答和进度；缺失或ID异常不静默重建 |
| 原有用户项目规则 | 不覆盖用户AGENTS；私人状态目录带独立Git忽略规则 |
| 聊天资料登记 | 指定文件/目录逐份保存、查重，排除配置和自身实例；失败保留已成功部分 |
| 无MCP后台 | 可初始化、设置、读资料、保留检索出处、完整题源练习、保存和导出 |
| 真实答复与订正 | 首答后知识点教学、等待重答再讲评；跨聊天续接，不修改原完成日期 |
| 原生自动任务 | 计划/创建/验证状态分开；保存真实回执，更新同ID，阻止重复任务及多设备抢占 |
| 阶段限制 | 第一阶段不建立监测任务或执行抓取，第二阶段起按授权和科目安排 |
| 迁移 | 停旧并记录disabled后才能释放所有者、在新机认领 |
| MCP规则和图像 | 通过真实stdio协议交付规则资源、提示入口和图片字节；无授权不读取私人图像 |
| 学习规则与导出 | 原有四阶段、题量、轮候、理论、原答/订正及PDF页码回归通过 |

测试只使用合成题目、隔离实例和标明“合成宿主”的回执，没有创建任何真实学习或监测任务。正常沙箱阻止本机HTTP连接时，受控授权后完成相应整套回归。没有修改作者个人学习实例、账号登录态或旧自动任务。
